# 🔀 Git & GitHub — Discussion Exercise

A class exercise for IN4MTX 43 — learning the basics of Git version control and GitHub collaboration workflows through hands-on practice.

![Git](https://img.shields.io/badge/Git-F05032?logo=git&logoColor=white)
![GitHub](https://img.shields.io/badge/GitHub-181717?logo=github&logoColor=white)

---

## 📚 What I Was Learning

Git fundamentals and GitHub collaboration — the version control workflow that every software project uses: initializing repos, making commits, pushing to remote, and working with branches.

---

## 🔑 Key Things Practiced

- **Git Basics** — `git init`, `git add`, `git commit`, `git push`
- **Remote Repositories** — Connecting a local repo to GitHub and pushing changes
- **Branching** — Creating and switching branches, understanding HEAD
- **GitHub Workflow** — Pull requests, merging, and collaborative version control concepts

---

## 💡 What It Taught Me

This exercise was my formal introduction to version control. Before it, I was saving project backups as folders with names like `project_v2_final_FINAL`. Learning Git showed me how developers actually manage code history — every change is tracked, reversible, and attributable. Understanding commits as snapshots (not diffs stored as raw text) changed how I thought about what git was doing. It was also my first experience with pull requests, which are now second nature in my workflow.
