# Git and GitHub — Discussion Exercise

A class exercise for IN4MTX 43, working through the basics of version control: initializing
a repository, staging and committing, pushing to a remote, branching, and opening a pull
request.

## What I took from it

This was my formal introduction to version control. Before it, I was saving backups as
folders named things like `project_v2_final_FINAL`, which works right up until you need to
know what changed between two of them.

The thing that actually clicked was understanding a commit as a snapshot rather than a
saved diff. Once that landed, the rest of Git stopped feeling arbitrary — branches are just
pointers at snapshots, and merging is a question about which snapshots share a common
ancestor.

It was also my first time opening a pull request, which is now such a routine part of how I
work that it's strange to remember learning it.
